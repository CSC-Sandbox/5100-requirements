# 34-enter-messages

# Design

## EnterMessages.java
Create a JFame which contains a textfield and button to send messages, to the server.
The button will not send empty messages. If the application is not connected to the server, then it will
ask you to start the server.

## Running Test
1. Start `TestEnterMessage.java` **first**
2. Start `EnterMessages.java`
3. Type in the Message you want to send to the test server.
4. Press the `send` button.
5. Look at the terminal for the TestEnterMessage.java process.
6. Repeat steps 3-5.
